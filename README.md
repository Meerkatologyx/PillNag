# PillNag

A native SwiftUI medication tracker for iOS 26+ that **keeps nagging until you take your meds**. It uses Liquid Glass throughout, AlarmKit for alarms that cut through Silent mode and Focus, and SwiftData stored only on the device.

## Features

- **Meds**: name, dose, pill shape, colors or SF Symbol icon, notes and a refill count with a low-supply warning.
- **Schedules**: daily times, specific weekdays, every X hours, or as-needed.
- **Nagging**: an AlarmKit alarm at dose time with **Stop** and **Snooze** buttons. Escalating follow-ups ring every N minutes up to a maximum count. Stop only silences the current alarm; the chain ends only when you mark the dose taken (or skip it) **inside the app**. Snooze restarts the chain later. If alarms aren't allowed, local notifications with a Snooze action are used instead.
- **Today** view with a progress ring and streak, **History** with an adherence chart, and day-by-day logs.
- **Customization**: accent color, glass tint and strength, light/dark/system, nag interval, max nags, snooze length and alarm sound. Each med can override the nag settings.

## How nagging works

`NagScheduler.rescheduleAll()` books every alert for the next 36 hours up front, so nags still fire if the app is never opened. It runs on launch, on foreground, after any change, from the alarm and notification Snooze buttons (via an App Intent running in the app's own process), and from background refresh.

## Building (no Mac needed)

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`. Never edit the `.xcodeproj` by hand; it isn't committed.

Every push to `main` runs `.github/workflows/build-ipa.yml` on a `macos-26` runner. The workflow generates the project, archives with `CODE_SIGNING_ALLOWED=NO`, ad-hoc signs the app (no certificate involved), packages `Payload/PillNag.app` into `PillNag-unsigned.ipa`, and uploads it as an artifact. The ad-hoc signature matters: on-device signers built on zsign (Feather, ESign, KSign) replace an existing signature block and can't sign a binary that has none, which makes the install prompt silently never appear.

```bash
gh run watch                                   # follow the latest run
gh run download --name PillNag-unsigned-<N>    # grab the IPA
```

Then sign the IPA yourself (for example with KravaSign and your `.p12` and provisioning profile). **Certificates, profiles and passwords never go in this repo**, and `.gitignore` blocks the common file types.

## Regenerating assets

`pwsh tools/generate-assets.ps1` redraws the placeholder app icon and the bundled alarm tones (`chime`, `pulse`, `rise`, `gentle`).

## v1 scope

No app extensions, widgets, App Groups or iCloud.
